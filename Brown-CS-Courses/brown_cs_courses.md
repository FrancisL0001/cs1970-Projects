# Brown University — CS Courses from Concentration Pathways (2020 Requirements)

> **Source:** [Pathways for Undergraduate and Master's Students](http://cs.brown.edu/degrees/undergrad/concentrating-in-cs/concentration-requirements-2020/pathways-for-undergraduate-and-masters-students/)
>
> **Note:** Individual course descriptions are not provided on the source page. The pathway description column reflects the umbrella description for each pathway. For full course descriptions, see the [Brown Course Catalog (CAB)](https://cab.brown.edu).
>
> **Status:** Pathways were removed for undergrads as of the 2024 requirements, and for Master's students as of the 2025 requirements. This list reflects the 2020 pathway structure.

---

## Pathways Overview

| Pathway | Description |
|---|---|
| **AI / Machine Learning** | Studies the theory and application of algorithms for making decisions and inferences from rules and data |
| **Computational Biology** | Studies algorithms for biological and genomic data analysis |
| **Computer Architecture** | Concerned with the design and analysis of hardware systems |
| **Data** | Studies the management and use of large data collections |
| **Design** | Addresses human-computer interfaces, interaction design, and creative computing systems |
| **Security** | Studies the design, construction, analysis, and defense of techniques to protect systems |
| **Software Principles** | Examines how to construct correct, maintainable, and efficient modern software systems |
| **Systems** | Covers multi-faceted computing infrastructure: OS, networks, distributed systems |
| **Theory** | Studies the foundations of models and algorithms for computing |
| **Visual Computing** | Addresses images, animation, graphics, and visual information processing |
| **Self-Designed** | Custom pathway with faculty approval (undergraduate only) |
